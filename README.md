## 🔬 Research Experience

### 🧪 Research Intern — NIT Kurukshetra
**Hyperspectral Imaging & Machine Learning**

Currently working on research based on **“Estimation of soil properties using Hyperspectral Imaging and Machine Learning”** published in *Smart Agricultural Technology (2025)*.

- 🌱 Soil property prediction using Hyperspectral Imaging + ML
- 📊 Feature Selection: F-Test, Mutual Information, Permutation
- 📉 Dimensionality Reduction: PCA, UMAP
- 🤖 Models: Linear Regression, ARD, PLSR, MLP
- 🔄 Evaluation using 2×5-fold Cross-Validation and R²
- 🧪 Properties: pH, EC, SOM, N, P, K, Ca, Mg, Fe, Cu, Mn, Zn, B
